# 📊 Retail Sales Analysis – Excel, SQL & Power BI

## 📌 Project Overview

A complete Retail Sales Analysis project developed using **Excel, SQL, and Power BI** to analyze sales performance, profitability, product performance, regional trends, and payment methods.

The project follows an end-to-end data analytics workflow — from **data cleaning and analysis to SQL querying and interactive dashboard development**.

---

## 🛠️ Tools & Technologies

- **Microsoft Excel** – Data Cleaning, Pivot Tables & Analysis
- **MySQL** – Data Analysis & Business Queries
- **Power BI** – Data Visualization & Interactive Dashboard

---

## 📂 Project Components

### 📗 Excel
- Data cleaning and preparation
- Pivot Table analysis
- Sales & profit analysis
- Product, category and regional analysis

### 🗄️ SQL
- Data querying and filtering
- Aggregation and business analysis
- JOINs, CTEs and subqueries
- Window functions
- Sales, profit and customer analysis

### 📊 Power BI
- Interactive sales dashboard
- KPI cards
- Monthly sales trend
- Category-wise sales
- Region-wise sales
- Top products analysis
- Payment mode analysis
